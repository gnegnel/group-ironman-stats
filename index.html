Data provided by the Wise Old Man API, which reads the official hiscores. The hiscores themselves only change when an account logs out, so anyone still online will show the levels they had when they last logged off. Update all stats asks Wise Old Man to re-read them; each account has a 60 second cooldown, so back-to-back presses will report the existing numbers.
